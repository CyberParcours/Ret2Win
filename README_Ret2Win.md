## 🎯 Objectif

L'objectif de **Ret2Win** est de progresser à travers plusieurs étapes
d'énumération et d'exploitation afin de récupérer les différents flags
et, finalement, obtenir les privilèges **root**.

La machine combine plusieurs domaines du pentest afin de proposer un
parcours CTF progressif.

## 🧠 Compétences travaillées

-   Reconnaissance réseau
-   Énumération de services
-   Énumération Web
-   Analyse d'applications Web
-   Exploitation Web
-   Upload de fichiers
-   Obtention et stabilisation d'un shell
-   Énumération Linux
-   Mouvement latéral
-   Élévation de privilèges
-   Analyse de binaires
-   Exploitation de Buffer Overflow
-   Analyse de tâches automatisées Linux

Les vulnérabilités exactes ne sont volontairement pas détaillées ici
afin de ne pas spoiler la machine.
